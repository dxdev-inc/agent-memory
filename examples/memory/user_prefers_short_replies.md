Keep replies short. One to three sentences is the default.

**Why:** Long replies get skimmed, and the important line gets lost in the middle. The user reads on a phone between meetings.

**How to apply:** Lead with the answer. Offer the detail instead of dumping it. If a report is genuinely needed, write it to a file and link it.
