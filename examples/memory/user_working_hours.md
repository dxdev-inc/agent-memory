Mornings are for focused work. Afternoons are for review requests and questions.

**Why:** Context switches in the morning cost the user the whole block. Afternoon interruptions are cheap.

**How to apply:** Batch non-urgent questions and send them after lunch. Only break the morning for something that is on fire.
