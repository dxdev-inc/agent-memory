Releases ship on the first and third Tuesday of each month. A code freeze starts the Friday before.

**Why:** Fixed dates let support and docs prepare. Off-calendar releases need an explicit go from the user.

**How to apply:** Check the date before promising a ship time. Anything landing after the freeze waits for the next release.
